# Значки типов тренировки — обсуждаемое ТЗ

Статус: не реализовывать до согласования критериев.

- Отдельные значки типов нагрузки слева от названия: гантель, бегущий человек и другие.
- Одновременно не больше двух значков. Правило выбора при трёх и более типах пока не утверждено.
- Значок не должен выдаваться только за добавление упражнения: учитывать выполненную работу и минимальный порог.
- Обсуждается три уровня цвета: бронза, серебро, золото.
- Для гантели пользователь предложил поднятый вес, для кардио — время. Конкретные пороги не утверждены.
- Уточнить, означает ли «поднятый вес» тоннаж за тренировку или максимальный рабочий вес.
- Для упражнений с собственным весом нужен отдельный критерий: нулевой тоннаж не означает отсутствие нагрузки.
- Уточнить критерии для удержаний, различие между отсутствием значка и бронзой, правило пересчёта после редактирования истории.
- Цвета и значки пока не добавлены в приложение.
