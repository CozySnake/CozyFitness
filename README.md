# CozyFitness 2.3.1

Мобильный дневник тренировок на HTML/CSS/JavaScript, без сборки. Публикуется на GitHub Pages из корня репозитория.

## Файлы и данные

- `fitness-data.js` — типы упражнений, единицы, форматирование, тоннаж, история, совместимость старых записей.
- `fitness-ui.js` — график истории и собственные SVG-медали.
- `workout-editor.js` — отдельный черновик редактора завершённой тренировки.
- `achievements.js` — условия, прогресс и даты получения 11 достижений.
- `app.js` — экраны, состояние, таймеры и обработчики.
- `sw.js` — офлайн-кэш. Все версии ресурсов перечислены явно.

Порядок скриптов в `index.html` важен. Сервер и библиотеки для работы приложения не нужны.

Режим встроенного упражнения закреплён в каталоге; у собственного задаётся при создании. Переключателей режима в тренировке и редакторе нет.

Типы: `strength` (weight в кг, reps), `timed` (durationSec), `cardio` (durationSec, distanceKm). В кардио UI принимает минуты, данные сохраняет в секундах. Тоннаж учитывает только силовые подходы, для двух гантелей — вес каждой × 2. Нулевой дополнительный вес допустим, повторения и время должны быть положительными.

Старые вес/повторения у планки и кардио сохраняются. Их нельзя достоверно пересчитать во время или расстояние; такие записи отмечены и исправляются вручную в истории. Тоннаж и достижения пересчитываются по текущей истории. Даты наград — дата первой тренировки, на которой было выполнено условие; исправление/удаление истории может изменить дату или убрать награду.

График показывает последние 20 тренировок, журнал — последние 10. Рекорды считаются за всю историю. Снаряды и типы измерений не смешиваются; доступен выбор группы. Для веса тела без отягощения график показывает повторения.

## Проверки

Из папки проекта с установленным Node.js:

    node tests/fitness-data.test.cjs
    node tests/achievements.test.cjs
    node tests/sheets.test.cjs
    node tests/modal-animation.test.cjs

`tests/browser.test.cjs` выполняет мобильный сценарий в отдельном временном профиле Edge через Playwright: ввод и сохранение трёх типов упражнений, редактор, отмена, забытый подход/упражнение, исправление старой планки, график и достижения. Пути к Edge и Playwright в тесте настроены под текущую рабочую машину. Реальный Safari/iPhone этим тестом не проверяется.

## Публикация 2.3.1

Перед обновлением экспортируйте текущие данные в JSON из профиля. Восемь файлов из архива `CozyFitness-2.3.1-update.zip` загружаются вместе в корень публикуемой ветки. Три новых файла (`fitness-data.js`, `fitness-ui.js`, `workout-editor.js`) обязательны. Иконки, manifest и существующие данные пользователя менять не нужно.
